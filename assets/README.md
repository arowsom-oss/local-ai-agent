# Local Studio app icon

Original artwork generated with the built-in image generation tool for this app.
No Apple, Python or other existing company logo is used. It is an abstract blue
three-ribbon intelligence core on a charcoal app tile.

- local-studio.png: 256 x 256 RGBA PNG, transparent outside the tile.
- local-studio.ico: Windows sizes 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixels.
- Only size/format conversion was applied after generation; the design is unchanged.

The app sets its own Windows process identity and window icon. A launcher shortcut
uses the ICO. Opening a .py file in Explorer still uses the system Python file
association; this app does not change associations or registry settings.

## Exact generation prompt

Use case: logo-brand. Asset type: final square Windows application icon for Local Studio, a private local AI assistant. Create one original, polished, simple emblem: a soft luminous blue intelligence core formed from three smooth interlocking rounded ribbons around a clear central negative space, contained within a charcoal rounded square app tile. Quiet premium desktop-software aesthetic, restrained color, crisp silhouette, balanced and centered, generous internal margins. Front-on flat graphic with very subtle dimensional shading; readable when reduced to 16, 32 and 48 pixels. Transparent area outside the rounded square tile. No text, no letters, no Python logo, no Apple logo, no existing AI brand mark, no watermark, no mockup, no multiple variants, no surrounding objects. The single tile should nearly fill the square canvas.
